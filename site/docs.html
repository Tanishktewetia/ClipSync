A GUIDE, NOT A GUESSING GAME

Let's get you
in sync.

From your first install to that little shortcut in Quick Settings. Here's how ClipSync fits into your day.

About this build: Current Windows and Android testing builds. Plain text, local network, no cloud clipboard. The Windows package is an installer; Android remains debug-signed until production signing is configured.

01 / Install on Android

  1. Download the Android APK on your phone, or transfer it using Telegram and save to Downloads. No USB or Developer options needed.
  2. Open the APK from Downloads. If Android asks, allow this browser or file manager to install unknown apps. Install ClipSync, then turn that permission off again if no longer needed.
  3. Open ClipSync and allow notifications for background status and the Send clipboard now action.
  4. Allow the one-time battery-optimization exemption when prompted. Manufacturer power controls can still affect background reliability.

Secure syncing needs Android 10+ with TLS 1.3. Never downgrade security for an older device.

Install updates over your existing test build to keep pairing. If Android reports a signature mismatch, verify the build rather than immediately uninstalling. Uninstalling erases your identity and requires pairing again.

02 / Install on Windows

Download the compact Windows x64 setup app. It installs ClipSync for your Windows account, adds it to Apps & features, and starts it quietly in the system tray whenever you sign in.

Download Windows installer ↓
  1. Download the setup EXE and compare its SHA-256 with SHA256SUMS.txt.
  2. Open the installer. The ClipSync application payload is kept small by using the Microsoft .NET 10 Desktop Runtime. If that runtime is missing, setup downloads the official Microsoft-signed runtime before continuing.
  3. When setup finishes, ClipSync opens from the notification area. Check the tray overflow menu if the icon is hidden.
  4. Keep Start ClipSync with Windows enabled in the ClipSync panel so syncing is ready after sign-in.
  5. Join the same private Wi-Fi as the phone. Choose Pair new device, tap Find a PC on Android, and confirm only when all six digits match.
Unsigned testing beta: the ClipSync setup EXE is not Authenticode-signed, so Windows may show an unknown-publisher or SmartScreen warning. Verify the source and checksum before deciding whether to run it; do not disable Windows security.

Uninstall ClipSync from Windows Settings → Apps → Installed apps. The installer is per-user and does not require you to manually move the application EXE.

Build from source

With the .NET 10 SDK installed, run from the repository root:

./scripts/build-windows-download.ps1
node site/build.cjs

The build creates a compact setup EXE containing the app and a runtime bootstrap check. It does not sign, run, or deploy the installer.

03 / Pair your devices

  1. Join the same reachable Wi-Fi network, or connect the phone to the Windows PC hotspot.
  2. Open ClipSync from the Windows tray and choose Pair new device. The pairing window lasts two minutes.
  3. On Android tap Find & pair my PC. Nearby services, saved addresses, and the actual Windows hotspot route are checked.
  4. Compare all six digits on both screens. Tap Codes match · Pair only when they match and you initiated pairing.
  5. Wait for Connected. Copy a test sentence on Windows and paste into a text field on the unlocked phone.

If discovery is blocked, use Android Advanced → Manual PC IP with the PC's Wi-Fi IPv4 address. A standard Windows hotspot commonly uses 192.168.137.1. Leave the field empty to use automatic discovery.

Finding a device is not trusting it. Every session still checks the certificate pin. Never approve an unexpected code or identity.

04 / What is a Quick Settings tile?

A tile is a shortcut button beside Wi-Fi, Bluetooth or the flashlight in the panel shown when you swipe down twice from the top of your phone. ClipSync adds one called Send to PC.

Add it

  1. In ClipSync tap Add Send to PC shortcut, or open Guide and tap Add Send to PC tile.
  2. On Android 13+, accept the system add-tile prompt.
  3. If no prompt appears, swipe down twice → tap Edit / pencil → find Send to PC among available tiles → drag into the active area → Done. Edit's position varies by phone.

Use it

  1. Copy plain text in any phone app.
  2. Open Quick Settings and tap Send to PC. Unlock if asked.
  3. Paste into a Windows text field.

Prefer not to add a tile? Use Send clipboard now in ClipSync's persistent notification instead.

Why a tap? Android restricts silent background clipboard reads. Copying on the phone alone never sends. After your action ClipSync briefly opens a focused read activity, reads plain text, then returns. No root, keyboard switching, Accessibility service or helper app.

05 / Everyday syncing

  • PC → phone: automatic when connected and unlocked.
  • Phone → PC: copy, then tap the notification action or tile.
  • Close the app screen: the foreground service stays enabled. Windows lives in the tray.
  • Lock: only the latest incoming PC text waits in memory, then applies on unlock.
  • Pause: stops both directions and clears pending text while the connection can remain active.
  • Stop background connection: disables recovery until you enable it again.
  • Restart: unlock once after boot; enabled sync is requested again. A force-stop in Android Settings requires opening the app manually.

Incoming Android clips are marked sensitive to hide their preview. Android may still show its system clipboard indicator. ClipSync does not promise to suppress all OS popups.

06 / Reconnect & conflicts

Recovery backs off after 1, 2, 5, 15, then at most 30 seconds. Network callbacks also trigger recovery. Matching Phase 7 peers use 15-second heartbeats and retire the link after two missed replies.

Each side keeps only the newest known text in memory. A logical counter orders updates; ties use a stable device-ID order. This is deterministic causal ordering, not a claim about which offline copy occurred last in wall-clock time.

  • PC changes can be captured while disconnected.
  • Phone text is only captured after your explicit notification/tile tap. If you copy offline but do not tap Send, ClipSync does not know about that copy.
  • Process death, stopping the service and reboot clear retained text. Closing the UI does not. No clipboard text is stored on disk.
  • Turn off Apply latest text on reconnect in Android Advanced to preserve that clipboard when connecting. Windows has the corresponding tray preference. New live updates still work.

07 / Privacy & security

  • Direct local-network text transfer with TLS 1.3 mutual authentication and pinned peer identities.
  • Android Keystore identity and encrypted peer fingerprint; Windows protected identity storage.
  • Explicit code-confirmed pairing. Discovery hints are untrusted.
  • No clipboard text in logs or disk history. Diagnostics include status, lengths and at most six hash characters.
  • Sensitive phone clips are skipped. Hash checks prevent received text from echoing back.
  • This website has no analytics, external fonts or account forms. Only light/dark theme preference is stored locally. GitHub has its own external-site policies.

Frames are bounded to 1 MiB; version metadata uses a small part of that limit. No images, iOS support, file transfer or internet relay in this beta.

08 / Get back in sync

Stuck on Waiting?

Confirm both apps are running, devices are on the same private network, and Windows Firewall allows ClipSync. Guest isolation or VPN routing can block local traffic. If mDNS is blocked, use the manual PC IPv4 fallback.

Can't pair?

Open a fresh pairing window on Windows, then pair from the phone. Compare the current code, not an old screenshot. Explicitly pair again only after an intentional device identity replacement.

Phone copy didn't arrive?

Unlock, copy plain text and tap Send to PC. Check neither side is paused. Sensitive clips are skipped. Copying alone is not a send command.

Background or reboot problems?

Check notifications and battery exemption. Unlock once after reboot. Manufacturer restrictions may still apply. A force-stopped app cannot silently restart itself.

Share useful diagnostics

Android: Advanced → Diagnostics → Share logs or Save to Downloads. Windows: Open Log Folder in the tray menu. Include both versions, Wi-Fi vs hotspot, and the action that failed. Never include confidential clipboard contents.
